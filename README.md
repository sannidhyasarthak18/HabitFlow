# HabitFlow 🍃
### Build Better Habits. Create a Better You.

HabitFlow is a modern habit-tracking iOS application built using **SwiftUI**. It is designed to help users develop consistency, monitor their daily routines, and track their personal growth through a clean and intuitive interface.

The application focuses on simplifying habit management while providing a dedicated space to monitor progress and stay motivated.

## ✨ Features

- **Habit Management:** Add and manage personal habits.

## 🏗️ Project Architecture

HabitFlow follows the Model-View-ViewModel (MVVM) architectural pattern.

```text
HabitFlow/
│
├── Models/
│   └── Habit.swift
│
├── ViewModels/
│   └── HabitViewModel.swift
│
├── Views/
│   ├── AddHabitView.swift
│   ├── HomeView.swift
│   ├── SettingsView.swift
│   └── StatisticsView.swift
│
├── Assets/
│
├── ContentView.swift
│
└── HabitFlowApp.swift
```

### Architecture Components

- **Model:** `Habit.swift` represents the habit data structure.
- **ViewModel:** `HabitViewModel.swift` manages application state and business logic.
- **Views:** SwiftUI views provide the user interface and user interactions.
- **App Entry Point:** `HabitFlowApp.swift` initializes the application.

## 🚀 Getting Started

Follow these steps to run HabitFlow locally.

### Prerequisites

- macOS
- Xcode
- Basic knowledge of Swift and SwiftUI
- iOS Simulator or a compatible iPhone

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/sannidhyasarthak18/HabitFlow.git
```

**2. Navigate to the project directory**

```bash
cd HabitFlow
```

**3. Open the project**

Open the `HabitFlow.xcodeproj` file in Xcode.

**4. Select a simulator**

Choose an available iPhone simulator from the Xcode device selector.

**5. Build and Run**

Press `Command + R` to build and launch HabitFlow.
